# Security policy

This repository is not yet release-qualified. Report suspected security defects
to the Plebian OS release owner through the private release-review channel; do
not attach real credentials, vaults, recovery material, private paths, or user
data. Reproductions must use generated synthetic fixtures.

Review B must reproduce the cryptographic negative vectors, allocation bounds,
authorization attacks, descriptor lifecycle, crash boundaries, memory/audit
failure policy, parser fuzz corpus, dependency closure, and pilot-consumer
behavior before integration is permitted.
